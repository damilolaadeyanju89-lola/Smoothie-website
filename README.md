# FruityFlow - Smoothie Website

A modern, responsive e-commerce website for a smoothie business featuring fresh, organic smoothie products with an elegant pink-themed design.

## 🌟 Features

### Navigation
- **Responsive Header** with fixed navigation bar
- **Mobile Toggle Menu** - Hamburger menu for screens ≤768px
- Navigation links: Home, About, Products, Review, Contact
- Quick access icons: Wishlist, Shopping Cart, User Account

### Sections

#### 1. Home Section
- Eye-catching hero section with background image
- "Fresh Smoothies" tagline
- "Natural & Nutritious Smoothies" subtitle
- Call-to-action "Shop Now" button

#### 2. About Us Section
- Video showcase of smoothie making process
- "Why Choose Us?" content area
- Centered pink "Learn More" button
- Informative text about the business

#### 3. Features Section
- Four key features displayed in cards:
  - **Free Delivery** - On All Orders

  - **Voucher & Gifts** - On All Others

- Hover effects on feature cards

## 🎨 Design Features

### Color Scheme
- **Primary Color**: Pink (#e84393)
- **Background**: White and light pink tones
- **Text**: Dark gray for headings, medium gray for body text

### Typography
- Main Font: Verdana, Geneva, Tahoma, sans-serif
- Capitalized headings and proper title case throughout
- Responsive font sizing

### Interactive Elements
- Smooth hover animations on buttons and links
- Product cards with lift effect on hover
- Animated hamburger menu transformation (menu to X)
- Smooth scrolling navigation
- Form input focus effects

### UI/UX Enhancements
- Pink accent color throughout
- Rounded buttons with hover effects
- Box shadows for depth
- Responsive grid and flexbox layouts
- Image blend effects in contact section

## 📱 Responsive Design

### Breakpoints
- **Large Screens** (>991px): Full desktop layout
- **Tablets** (768px - 991px): Optimized tablet view
- **Mobile Landscape** (450px - 768px): Mobile-optimized layout with hamburger menu
- **Mobile Portrait** (<450px): Compact mobile view

### Mobile Features
- Toggle navigation menu
- Stacked sections for better readability
- Touch-friendly button sizes
- Optimized images and spacing
